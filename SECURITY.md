# Security policy

Please report security vulnerabilities privately by email to
**security@nulegal.de** — not in a public GitHub issue.

Include what you found, how to reproduce it, and the impact you expect. We
will acknowledge your report, keep you informed while we work on it, and credit
you when the fix is released if you would like that.

This policy covers the code in this repository and the hosted MCP endpoint at
`https://recht.nulegal.eu/v1/mcp`. Please do not run load tests or automated
scanners against the hosted service; a report about the code alone is enough.

## Supported versions

Only the latest commit on `main` is supported. The hosted endpoint runs a
pinned commit of `main`.
